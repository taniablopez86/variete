Acceso al panel

Pega la clave de acceso (token de GitHub). Se guarda solo en este navegador.

¿Cómo obtengo la clave?
  1. Entra a GitHub con la cuenta dueña del repositorio y abre Crear token.
  2. En Repository access elige Only select repositories y selecciona .
  3. En Permissions → Repository permissions → Contents elige Read and write.
  4. Pon una fecha de vencimiento, pulsa Generate token y copia la clave aquí.
